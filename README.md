# Physical Gear Public

Physical Gear Publicは、3Dプリント部品、一般的なRCサーボ、Arduino、Unityを組み合わせて製作するPROJECT SALIERIの10軸上半身ロボットプロジェクトです。

このリポジトリは、Physical Gear Public v0.1.0-betaの公式紹介・組立資料を公開するためのものです。

## Website

GitHub Pagesのソースは`docs/`に配置しています。

公開URL：

`https://hazama714.github.io/Physical-Gear-Public/`

## Distribution

STL、Windows EXE、Unityアセット、Arduinoスケッチをまとめた配布ZIPはBOOTHから提供する予定です。BOOTH商品URLが確定するまで仮リンクやダウンロードボタンは掲載しません。

GitHub Releasesは配布ZIPの提供先として使用しません。
